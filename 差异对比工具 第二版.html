DiffLab 使用说明

A 与 B 是只读的对照源；你的编辑只发生在「合并编辑」产生的第三份结果里，互不混淆。未变化的内容自动合并进结果。

1–7切换 输入 / 并排 / 统一 / 修订 / 织带 / 合并 / 结果
n j / p k下一处 / 上一处差异
a / b合并视图：当前差异采用 A / B
x / e合并视图：清空当前差异 / 编辑当前差异
Ctrl+Z / Y撤销 / 重做 合并选择
Ctrl+Enter在输入页立即对比
?打开本帮助

视图

  • 并排 / 统一：经典行级对比，行内词/字符级高亮，未变内容可折叠。
  • 修订：像 Word 修订模式，删除线与新增合在同一段文字里，适合文章。
  • 织带（原创）：把 A、B 当作两条纸带，用彩色丝带连接对应位置；一眼看出哪里增删、哪里挪位，点击丝带定位。
  • 合并编辑：每处差异一张卡片，可采用 A / B / A+B / B+A / 清空，或直接在「结果」框里改字。

可拖拽文件到输入框；自动识别 UTF-8 / GBK 编码；所有处理均在本地完成。
