双向同步建议

让浏览器 B 获得 A 的独有收藏
  1. 点击「导出 A→B 差异」下载 HTML
  2. 在浏览器 B 中：书签管理器 → 导入书签
  3. 选择刚下载的差异文件即可
让浏览器 A 获得 B 的独有收藏
  1. 点击「导出 B→A 差异」下载 HTML
  2. 在浏览器 A 中：书签管理器 → 导入书签
  3. 选择刚下载的差异文件即可

提示：也可直接「导出完整合并收藏夹」作为统一备份，再分别导入两边。本工具完全在浏览器本地运行，不会上传你的收藏夹数据。

纯前端 · 数据不离开本机 · 兼容 Netscape / Chrome / Edge / Firefox 收藏夹 HTML 格式

使用说明

如何导出收藏夹？

  • Chrome / Edge：书签管理器 → 右上角 ⋮ → 导出书签
  • Firefox：书签 → 管理书签 → 导入与备份 → 导出书签到 HTML
  • Safari：文件 → 导出 → 书签…

匹配方式说明

  • 按 URL：相同网址视为同一条（推荐）
  • URL + 标题：网址和标题都相同才算同一条
  • 规范化 URL：忽略 http/https、www、末尾斜杠、#fragment 等差异

隐私

所有解析与对比均在你的浏览器本地完成，不会发送到任何服务器。
