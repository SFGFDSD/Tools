# JISHENG OS 应用开发指南

> 适用版本：V10.5.8+
> 标记格式：v2（应用名 + SVG图标，两个键；旧版 JSON 格式仍然兼容）

## 1. 简介

JISHENG OS 支持用户通过简单的 HTML 注释声明应用。当一个 HTML 文件包含特定的应用声明标记时，JISHENG OS 会将其识别为独立应用，而不是在浏览器中打开。应用窗口不会显示浏览器地址栏，并且默认最大化打开，提供更加原生的应用体验。

你只需要一个 HTML 文件，在注释里写清"应用名"和"应用图标"两样东西，就可以让它成为 JISHENG OS 应用。标记不再要求 JSON：图标从任何网站复制之后原样粘贴即可，不用转义引号、不用改写格式。

---

## 2. 快速开始

### 2.1 最小示例

创建一个新的 HTML 文件，在文件开头添加应用声明标记：

```html
<!--JISHENG-OS-APP 应用名：我的应用-->
<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="UTF-8"><title>我的应用</title></head>
<body>
    <h1>Hello JISHENG OS!</h1>
</body>
</html>
```

标记只有这两行。没有写图标时，系统使用默认图标。

将这个文件上传到 JISHENG OS 桌面，双击即可以作为独立应用打开——没有浏览器地址栏，窗口默认铺满屏幕，窗口标题显示为"我的应用"。

### 2.2 带图标的应用

把图标从任何网站复制过来，原样贴到 `SVG图标：` 下面：

```html
<!--
JISHENG-OS-APP
应用名：我的应用
SVG图标：
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor">
    <circle cx="12" cy="12" r="9"/>
    <path d="M12 8v4l3 2"/>
</svg>
-->
```

不需要改引号、不需要转义、不需要写 `width` / `height` —— 尺寸由系统按显示位置决定（桌面 36px、窗口标题栏 16px、任务栏 18px）。

## 3. 应用标记格式

### 3.1 标记语法

应用声明使用 HTML 注释。注释里只需要三样东西：标记名、应用名、图标。

```html
<!--
JISHENG-OS-APP
应用名：应用名称
SVG图标：
<svg ……>……</svg>
-->
```

- 标记必须写在注释（`<!-- -->`）里，并且位于文件的**前 100 行**内；
- 注释里的 SVG 不受这 100 行限制，再长也没关系；
- 标记在注释里的位置随意，两个键的先后顺序也随意。

### 3.2 应用名

`应用名：` 后面那一行只写名字。键名大小写不敏感，冒号、全角冒号、等号都可以：

| 写法 | 示例 |
|------|------|
| 中文键名 | `应用名：计算器` |
| 英文键名 | `NAME: 计算器` |
| 等号 | `名称=计算器` |
| 直接写在标记名后面 | `<!-- JISHENG-OS-APP: 计算器 -->` |
| 键名后留空，名字写在下一行 | `应用名：` 换行 `计算器` |

可以使用的键名：`应用名`、`应用名称`、`名称`、`名字`、`标题`、`软件名`、`程序名`、`NAME`、`APP`、`APPNAME`、`TITLE`。

以上都没写时，系统依次使用 `<title>` 标签、文件名（去掉扩展名）、"未命名应用"兜底。

**建议：** 名字控制在 20 个字以内。系统最多保留 60 个字，超出的部分会被截断。

### 3.3 应用图标

图标键与 `应用名：` 对称，写法有 `SVG图标：`、`图标：`、`SVG：`、`ICON:`、`应用图标：`。

图标内容放在这个键的下面（推荐，SVG 一般很长），也可以紧跟在同一行。

图标支持两种粘贴方式：

| 粘贴内容 | 系统处理 |
|----------|----------|
| 完整 SVG（`<svg ……>` 到 `</svg>` 整段） | 原样使用：自动补 `xmlns`、按 `width` / `height` 换算 `viewBox`、清掉写死的宽高 |
| 只有内部图形（`<rect/>`、`<path/>` 等，没有外层 `<svg>`） | 自动补一层 `viewBox="0 0 24 24"` 的外壳，并渲染为线条风格（`fill="none" stroke="currentColor"`） |

写了 `SVG图标：` 之后，系统从这一行往后找图标，注释前面提到的 SVG 不会被误选。没写图标键时，系统在整个注释里找第一个完整 SVG；都没有则使用默认图标。

**配色规则**（粘贴的图标自带颜色时，系统不会改动）：

| 图标情况 | 系统处理 |
|----------|----------|
| 自带 `fill` / 多色图标 | 原样保留，不添加描边 |
| 只有 `stroke`（没写 `fill`） | 补 `fill="none"`，避免被默认的黑色填充 |
| 线条风格且没写 `stroke-width` | 补系统默认值 `1.5`；你自己写了（比如 Lucide 的 `2`）则保留你的值 |
| 完全没有颜色信息 | 按实心图标补 `fill="currentColor"` |

### 3.4 注释里的其它内容

标记注释里可以自由添加说明文字、分隔线（`=====`、`-----`）、模板提示语，系统会自动忽略这些行。下面这种自解释写法同样可以正常运行：

```html
<!--
JISHENG-OS-APP
应用名：写在这里（只写名字）
SVG图标：从任何网站复制的 SVG 贴到这一行下面
<svg viewBox="0 0 24 24"><path d="M5 5h14v14H5z"/></svg>
-->
```

## 4. 完整示例

### 4.1 带完整配置的应用

以下是一个包含自定义图标的完整示例：

```html
<!--
JISHENG-OS-APP
应用名：差异对比
SVG图标：
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-linecap="round" stroke-linejoin="round">
    <path d="M12 3v18M3 12h18M8 8l-5 4 5 4M16 8l5 4-5 4"/>
</svg>
-->
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>差异对比</title>
    <style>
        body { font-family: sans-serif; padding: 20px; }
    </style>
</head>
<body>
    <h1>差异对比工具</h1>
</body>
</html>
```

不需要再声明窗口尺寸：应用一律最大化打开。用户点击标题栏的最大化按钮，可以把窗口还原成默认大小（约 1000×700），也可以直接拖拽窗口边缘自行调整。

### 4.2 自定义图标说明

图标建议使用 `24x24` 视口的简洁线条图形，与 JISHENG OS 系统图标风格保持一致。

**推荐风格：**
- 使用 `stroke` 线条风格
- `stroke-width` 设为 `1.5`
- `fill` 设为 `none`
- 视口 `viewBox` 为 `0 0 24 24`
- `stroke-width` 可以省略：系统按默认值 `1.5` 渲染；写了自己的值就按你的来

**示例图标（差异对比图标）：**

```html
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor">
    <path d="M12 3v18M3 12h18M8 8l-5 4 5 4M16 8l5 4-5 4"/>
</svg>
```

**省略图标时使用默认图标：**

```html
<!--
JISHENG-OS-APP
应用名：记事本
-->
```

### 4.3 旧版 JSON 格式（兼容）

旧版 JSON 标记仍然可以识别，不需要急着改：

```html
<!-- JISHENG-OS-APP: {"name":"我的应用","icon":"<svg ……>……</svg>","width":700,"height":500} -->
```

- `width` / `height` 已废弃，写了也会被忽略（应用一律最大化打开）；
- JSON 里的图标双引号必须转义（写成 `\"`），这是旧格式最容易写错的地方，也是新格式改成直贴的原因；
- 标记写得不是合法 JSON 时，系统会按新格式继续解析，名字和图标能认出来就用，不会再直接忽略整个标记。

## 5. 部署方式

完成开发后，有两种方式将应用部署到 JISHENG OS：

### 5.1 方式一：上传到桌面

直接将 HTML 文件拖拽到 JISHENG OS 桌面上，或通过文件管理器上传。双击文件即可作为应用打开。

### 5.2 方式二：放入仓库

将 HTML 文件放入本仓库中，其他用户可以通过仓库获取并使用你的应用。

## 6. 注意事项

- 标记必须写在 HTML 注释里，且位于文件的**前 100 行**内（系统只搜索前 100 行；注释里的 SVG 不受这 100 行限制）
- 标记不再要求**有效的 JSON 格式**：注释里认不出名字或图标时，系统用 `<title>`、文件名、默认图标兜底
- 应用名不是必填项；连键名都不写时，系统会取图标上方最近的一行普通文字作为名字
- 应用窗口**一律最大化打开**，`width` / `height` 不再需要；想改大小，点标题栏的最大化按钮或直接拖窗口边缘
- **粘贴图标前，先删掉 SVG 里自带的 `<!-- -->` 注释**（从 FontAwesome 一类站点复制的图标会带版权注释）。HTML 注释不能嵌套，那段注释会把外层的应用标记提前截断，导致图标少一截或退回默认图标
- 同一个文件只认**第一个**应用标记
- 应用运行在 iframe 中，支持 JavaScript、表单提交、弹出窗口（sandbox 策略）
- 应用窗口**不含浏览器地址栏和导航按钮**，提供更原生的应用体验
